# 网球 & 皮克球装备线上商城小程序

这是一个可直接导入微信开发者工具的商城小程序示例，主题为**网球装备**与**皮克球装备**。

## 功能清单

- 首页活动与热卖商品展示
- 分类筛选（网球拍、网球、网球服饰、皮克球拍、皮克球、网架）
- 商品详情页
- 购物车（勾选、增减数量、删除、汇总）
- 个人中心（示例数据）

## 目录结构

- `app.js / app.json / app.wxss`：全局配置与全局购物车状态
- `data/products.js`：商品与分类数据
- `utils/currency.js`：价格格式化工具
- `pages/home`：首页
- `pages/category`：分类页
- `pages/product`：商品详情页
- `pages/cart`：购物车页
- `pages/profile`：个人中心页

## 本地运行

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向当前仓库。
3. 使用测试号 / 游客模式（`project.config.json` 中 appid 为 `touristappid`）。
